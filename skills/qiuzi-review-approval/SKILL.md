# Qiuzi Review Approval

## 用途

此 Skill 只负责“审查意见确认后再修改”的受控流程：验证 Review、制定方案、等待用户确认，并仅在确认后实施已确认的问题。

## 执行入口

1. 收到 Review 意见后，先识别意见来源、涉及文件和预期行为。
2. 读取并遵循 [prompt.md](prompt.md) 的完整工作流；其中的硬性停止门禁优先于任何默认编码习惯。
3. 需要用户确认时，严格输出 `prompt.md` 规定的“等待确认”区块后停止。

## 非适用范围

- 用户没有提供既有 Review 意见，只是要求审查代码；
- 用户要求直接实现功能、修复已明确确认的缺陷，且不需要审查意见核查；
- 仅要求解释、翻译或整理 Review 文本，且不涉及后续修改决策。
